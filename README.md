# A股ETF每日看板（GitHub Pages 版）

- `index.html`：当日看板，图片已内嵌 base64，可直接在浏览器打开渲染，无需额外资源。
- `.nojekyll`：告诉 GitHub Pages 不要用 Jekyll 处理，保证 HTML 原样 served。
- `etf_system.py`：抓取、打分、回测、生成看板的主脚本（东方财富公开行情接口，无需 API Key）。
- `.github/workflows/daily-etf.yml`：GitHub Actions 定时任务，周一至周五北京时间 8:30 自动跑脚本、生成看板并提交回仓库，Pages 随之更新，无需人工审批；手动触发（workflow_dispatch）时强制发布，用于测试。
  - 无新交易日数据时（数据截至日与上一版相同，如节假日）自动跳过提交，避免用旧数据刷出新版本。
  - 对比基准：上证指数（000001）与沪深300指数（000300），指数本身而非 ETF 价格；顶部相对超额仍以沪深300ETF（510300）为基准，口径不同需区分。
- 注意：本看板为量化分析与信息参考，不构成买卖建议；历史回测不代表未来收益。

- `holdings.json`：我的持仓清单（模拟数据演示，非真实持仓），用户可在 GitHub 网页直接编辑：改代码、市场（A股/港股通）、买入日期、数量、买入价，Actions 下次运行自动更新持仓区块；港币按文件里的 hkd_cny 折人民币。
